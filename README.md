# Dashboard de Vendas no Excel

## Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio de análise e visualização de dados, com o objetivo de transformar dados brutos em informações visuais que facilitem a compreensão dos resultados.

O dashboard foi elaborado no Microsoft Excel e utiliza uma base de dados de assinaturas do Xbox.

## Objetivos

- Organizar e visualizar os dados de forma clara.
- Analisar a distribuição dos assinantes por plano.
- Comparar valores registrados entre diferentes planos.
- Examinar informações sobre modalidades de assinatura, renovação automática e serviços adicionais.
- Explorar a utilização de cupons e os valores associados às assinaturas.

## Ferramentas utilizadas

- Microsoft Excel
- Tabelas dinâmicas
- Gráficos e indicadores
- GitHub para versionamento e documentação do projeto

## Dados utilizados

A base de dados contém informações sobre assinantes, planos contratados, modalidades de assinatura, datas de início, renovação automática, serviços adicionais, cupons e valores registrados.

## Como visualizar o projeto

1. Acesse o arquivo `dashboard_vendas.xlsx` neste repositório.
2. Clique em **Download** para baixar a planilha.
3. Abra o arquivo no Microsoft Excel.
4. Acesse a aba `Dashboard` para visualizar os resultados.

## Estrutura do projeto

- `dashboard_vendas.xlsx`: arquivo Excel com a base de dados, os cálculos e o dashboard.
- `README.md`: documentação do projeto.

## Observações

Os resultados apresentados dependem dos dados disponíveis na base utilizada. Os valores registrados não devem ser interpretados como lucro sem informações adicionais sobre custos.
